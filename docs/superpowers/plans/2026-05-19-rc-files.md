# RC Files Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make generated rc files safer, more portable, and easier to explain in the chooser.

**Architecture:** Shared rc files stay under `common/`; chooser metadata stays near `configDefinitions` in `chooser/src/main.tsx`. The chooser imports raw rc content, so line ranges must be updated with each rc file change.

**Tech Stack:** Bash, zsh, tmux, Vimscript, Git config, React, TypeScript, Vite.
