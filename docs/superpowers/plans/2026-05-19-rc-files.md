# RC Files Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make generated rc files safer, more portable, and easier to explain in the chooser.

**Architecture:** Shared rc files stay under `common/`; chooser metadata stays near `configDefinitions` in `chooser/src/main.tsx`. The chooser imports raw rc content, so line ranges must be updated with each rc file change.

**Tech Stack:** Bash, zsh, tmux, Vimscript, Git config, React, TypeScript, Vite.

---

### Task 1: Harden shared rc files

**Files:**
- Modify: `common/.zshrc`
- Modify: `common/.vimrc`
- Modify: `common/.tmux.conf`
- Modify: `common/.gitconfig`

- [ ] Add an interactive guard, local pre-hook, safer locale defaults, and post-hook to `.zshrc`.
- [ ] Remove Vim startup network download behavior and wrap filetype autocmds in an augroup.
- [ ] Add tmux truecolor defaults and `pbcopy` fallback to copy-mode clipboard commands.
- [ ] Add Git `zdiff3`, histogram diff, and rerere defaults.
- [ ] Run `./scripts/check.sh`.
- [ ] Commit with `refactor: harden rc defaults`.

### Task 2: Explain rc block risks in the chooser

**Files:**
- Modify: `chooser/src/main.tsx`
- Modify: `chooser/src/styles.css`

- [ ] Extend `ConfigBlock` metadata with a `kind` value.
- [ ] Update config block line ranges after rc file edits.
- [ ] Render a compact metadata row for block kind, order risk, shortcuts, and plugin side effects.
- [ ] Disable drag handles for locked blocks only if the implementation can do so without confusing keyboard users; otherwise keep drag enabled and make the warning explicit.
- [ ] Run `npm --prefix chooser run check`.
- [ ] Commit with `feat: explain config block risks`.

### Task 3: Final verification

**Files:**

- [ ] Run `./scripts/check.sh`.

- [ ] Commit any final documentation adjustment if needed.
