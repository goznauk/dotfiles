# Maintenance Reports

These reports are work logs for review, validation, and UI/UX passes. They are not the primary user documentation. Start with the top-level `README.md`, `Ubuntu/README.md`, and `chooser/README.md` for current usage.

Reports can include historical notes from the state of the repository at the time they were written. When a report mentions older structure, prefer the current source tree and newer reports for present-day ownership. In particular, the chooser entry wrapper is `chooser/src/main.tsx`, while the main app surface is now `chooser/src/App.tsx`.

Temporary screenshot paths under `.tmp/` are referenced as QA evidence only. Those screenshots and manifests are ignored and are not committed.

## Reports

- `full-codebase-sweep-report.md`: ten-iteration repository maintenance sweep and validation work log.
- `ui-ux-agent-review.md`: broad chooser UI/UX screenshot review and improvement pass.
- `config-editor-ux-review.md`: focused Config editor redesign review.
- `project-structure-review.md`: current project structure review and follow-up recommendations.
